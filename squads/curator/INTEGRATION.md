## Quick Start

Use `@curator-chief` for all content management, curation, and multimedia production decisions.

```
@pm → curator-chief (content strategy)
  → content-miner-pro (content discovery)
  → timestamp-cataloger (organization)
  → data-curator (metadata)
  → ken-burns-specialist (visual style)
  → walter-murch-editor (editing)
  → matthew-dicks-storyteller (narrative)
  → robert-mckee-structure (story structure)
  → brendan-kane-virality (viral mechanics)
  → jonah-berger-psych (psychology)
  → mrbeast-formatter (content format)
```

## When to Activate Curator

- [ ] Need content curation or discovery strategy
- [ ] Planning video production pipeline
- [ ] Creating multimedia content
- [ ] Optimizing content for virality
- [ ] Developing narrative strategy
- [ ] Building content library
- [ ] Designing content distribution

## How to Activate

1. Story involves content curation or video production
2. **@pm routes to curator-chief** (primary router)
3. curator-chief executes with other Curator specialists as needed
4. Results delivered as: content strategy, video content, editorial guides, viral mechanics

## Delegation Rules

| Decision Type | Agent | Output |

| Content strategy | curator-chief | Content plan, workflow, distribution strategy |
| Content mining | content-miner-pro | Content discovery, sources, ideas |
| Organization | timestamp-cataloger | Cataloging system, timeline, metadata |
